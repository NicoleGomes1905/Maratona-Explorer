# Maratona Explorer

A simple client-side question-and-answer web app built with HTML, CSS, and JavaScript. This project is structured for practice with a clean GitHub repository layout and English documentation.

## About

Ask any question and the app responds with a randomly selected answer, similar to a digital "magic 8-ball".

## Project structure

- `index.html` — the main application page
- `styles/style.css` — styling for the UI
- `scripts/app.js` — application logic and user interaction
- `assets/crystal-ball.svg` — decorative image used in the interface

## Features

- Responsive layout
- Clean separation of HTML, CSS, and JavaScript
- English UI text
- Safe text rendering using DOM methods

## How to run

1. Open `index.html` in your browser.
2. Type a question in the input field.
3. Click "Ask Question" to see the response.

## Notes

- The page is static and works without a server.
- Keep the `assets`, `styles`, and `scripts` folders together with `index.html`.
